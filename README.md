# Aristote 4 All — kiosque de tutorat socratique

*AI is here! why not supercharge teaching?*

Kiosque éducatif de bureau partagé par 4 élèves : tuteur IA socratique, scan de copies manuscrites,
impression d'exercices sur ticket thermique, et remontée automatique des données vers le coffre Obsidian du professeur.
